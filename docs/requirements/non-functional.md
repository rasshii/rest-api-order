# 機能でない要件

何ができるかではなく、どんな条件でも守ることと、どの程度に守るかの要件。確かめ方と、扱う周回を一緒に書く。確かめ方を書けない要件は、確かめられる文に書き直す。

| 要件 | 確かめ方 | 扱う周回 |
| --- | --- | --- |
| 同じ商品への注文が同時に来ても、在庫より多くは引き当てない | 在庫が 1 の商品に、1 個の注文を同時に 2 件送り、受け付けられるのが 1 件だけであることを確かめる | 1 周目 |
| 予期しない誤りの応答に、内部の情報 (スタックトレースや SQL の文) を載せない。代わりに追跡 ID を載せ、同じ追跡 ID をログにも残す | 誤りを起こしたテストで、応答の本文とログを確かめる | 1 周目 |
| 同じ注文を送り直しても、注文が 2 件にならない | 同じ注文を 2 回送り、注文が 1 件だけ記録されることを確かめる | 3 周目 |
| 注文の内容は、その注文をした会員だけが読める | 別の会員で読もうとすると、読めないことを確かめる | 4 周目 |

1 周目のあいだは、3 周目と 4 周目の要件を満たさない。とくに、注文 ID を知っていれば、誰でもその注文を、連絡先メールアドレスを含めて読める。
