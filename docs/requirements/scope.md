# 1 周目に入れないもの

1 周目は、注文することと、注文を確かめることだけを扱う。次のものは入れない。入れないあいだの扱いも書いておく。

| 入れないもの | 扱う周回 | 1 周目のあいだの扱い |
| --- | --- | --- |
| 商品を探して見る | 2 周目 | 購入者は、商品をこの API で探せない。受け入れ条件の商品と在庫は、前もって登録しておく |
| 注文を取り消す、注文を変える | 3 周目 | 受け付けた注文は、内容も状態も変えられない |
| 会員と管理者、在庫の入荷 | 4 周目 | 誰でも注文できる。在庫は注文で減るだけで、増やす操作は無い |
| 決済、連携先への知らせ、商品画像、商品と在庫の取り込み | 5 周目 | 注文は受付の状態のまま進まない |
